# Teknoloji
- Unreal Engine 5: Landscape, PCG, gerektiğinde Nanite/Lumen ve World Partition. Kararlı uyumlu sürüm seç ve sabitle. Unity C# ve Godot hafif/metin tabanlı alternatifler; PoC başarısızsa yeniden değerlendir.
- Claude Code: Pro başlangıç, Max gerekirse. Abonelik oturumu doğrula, API anahtarıyla yanlış faturalandırmadan kaçın. Kesintisiz otonomi garanti değil.
- Visual Studio C++ araç zinciri, Git + Git LFS, Python + Editor Utilities. Unreal MCP deneysel/opsiyonel; güvenlik ve sürüm uyumluluğu PoC olmadan bağımlılık değil. Python runtime mekanikleri için değil.
- Blender, Fab: önce lisanslı hazır modeller; Tripo opsiyonel, Mixamo karakter fazında. Ölçek, UV, materyal, poligon, collision, LOD, lisans ve kaynak kaydı.
- QGIS + DEM: koordinat, yükseklik/eğim/bakı, heightmap; Cesium opsiyonel. İklim profili ve güneş hesabı. Küçük parsellerde DEM çözünürlüğü sınırlı; kaynak ve doğruluk bildirimi, mühendislik doğruluğu iddiası yok.
- Audacity, opsiyonel Reaper: ses fazında. Çekirdek oyun çevrimdışı, Windows PC. UE lisans ve Fab varlık koşullarını kurulum/satın alma öncesi resmî kaynaklardan tekrar doğrula.
