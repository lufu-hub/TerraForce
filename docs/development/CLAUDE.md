# Claude çalışma sözleşmesi
Önce docs/development/CURRENT_STATE.md, DECISIONS.md ve ilgili backlog görevini oku. Tüm projeyi her turda yeniden okuma. Yalnızca ilgili dosyaları ve bağımlılıkları incele. Küçük değişikliklerde hedefli test, entegrasyonlarda geniş test; faz sonunda build ve oynanabilir kabul testi. Hataları önce kendin teşhis et ve güvenli düzelt; başarısız testi gizleme. Başarılı paket sonrası Git checkpoint ve kısa durum güncellemesi. İzin ve abonelik sınırları içinde sıradaki hazır göreve geç; oturum sınırında checkpoint bırak. Harcama, veri kaybı, büyük mimari/kapsam değişimi veya belirsiz ürün kararı için onay al. İlgisiz yerel değişiklikleri commit etme; force push, reset veya silme yapma. Ücretli API yok. Master Tree revizyonu tamamlanmadan düğümleri sabitleme. Mevcut prototipi koru. Rapor: tamamlananlar, test kanıtı, risk, sonraki görev, gerekli karar. Bu dosya alt klasördedir; oturum başında açıkça okutulmalıdır.
