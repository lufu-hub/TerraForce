# Teknoloji ve Üretim Master Planı v1.0
24 Kasım 2026 — tasarım referansı, uygulama durumu değil.
Amaç: kodlama bilmeyen tek ürün sahibinin Claude Code ile sürdürülebilir Windows oyunu geliştirmesi. Kullanıcı oyun deneyimi ve kritik kararları; Claude kod, otomasyon, test ve hata düzeltmeyi yönetir. Unreal Engine 5 birincil aday; Unity ve Godot alternatif. Motor seçimi erken teknik PoC ile doğrulanır. C++ çekirdek, Blueprint gerektiğinde, Python editör otomasyonu. Ücretsiz araç ve Pro ile başla, Max ancak ölçülen limit engeli halinde. Ücretli servis, varlık veya API onaysız yok.
İlk hafta hedefi: boş proje, kamera, arazi, bir yapı ve paketlenmiş oyun; hedef garanti değil. Altı hafta: sentetik 10 dönüm, iki kamera modu, 3–4 yapı, eğim/çakışma, zaman, kayıt ve Türkçe arayüz. Sonra inşa, kaynak, aile, gerçek arazi, dikey oyun dilimi. 12 ay haftada 10–15 saat varsayımıyla tahmini, tam oyun teslimi değil. Faz geçişleri kabul testine bağlı.
Simülasyon ile 3D sunum ayrılır; veri odaklı modüller, sürümlü kayıtlar, tekrarlanabilir build. Detaylar diğer belgelerde. Mevcut web prototipi varsa önce incele ve koru; motor geçişi ayrı karar. Windows RTX 4060; CPU/RAM/SSD doğrulanmalı. İlk hedef 1080p, 30 FPS alt sınırı ve uygun sahnelerde 60 FPS ölçüm hedefi. Kapsamı genişletmeden çalışan çekirdeği doğrula.
